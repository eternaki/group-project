### Pipeline preprocessing (po naprawie Sprint 9)


## Zidentyfikowane błędy

### Błąd #1: Brak konwersji BGR→RGB (KRYTYCZNY)

**Problem:** OpenCV zwraca obrazy w formacie BGR. `transforms.ToPILImage()` na
ndarray zakłada RGB. Efekt: kolory pomieszane (kanał B zamiast R).

**Naprawa:**
```python
# W preprocess() — przed transforms:
image = image[:, :, ::-1].copy()  # BGR→RGB
```

### Błąd #2: Zła rozdzielczość (img_size=224 zamiast 380)

**Problem:** EfficientNet-B4 jest wytrenowany na 380×380. Użycie 224 zmniejsza
dokładność (utrata ~2-3% Top-1 accuracy).

**Naprawa:** Zmiana domyślnej wartości `img_size=380` w `BreedConfig`.
