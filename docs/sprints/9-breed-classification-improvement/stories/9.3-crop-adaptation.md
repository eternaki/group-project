# Story 9.3: Adaptacja croppów psów

**Status:** Done
**Sprint:** 9
**Priorytet:** Medium

## Opis

Poprawa przetwarzania croppów psów z bounding box. Psy mają różne proporcje
(długie, krótkie, duże uszy itp.) — proste CenterCrop może ucinać fragmenty.

---

## Problem: Nierównomierny crop

Bounding boxy psów rzadko są kwadratowe. Przykładowe proporcje:
- Pies siedzący bokiem: ~0.7:1 (szerszy niż wysoki)
- Pies z długą mordą: ~1.5:1 (wyższy niż szeroki)
- Labrador z przodu: ~1:1

Bez square paddingu, `Resize → CenterCrop(380)` ucina boczne/górne fragmenty.

## Rozwiązanie: SquarePad

Klasa `SquarePad` dodaje padding (czarny) do krótszego wymiaru, tworząc
kwadratowy obraz przed resize. Zachowuje cały bounding box psa.

```
Oryginalny crop (np. 200×300):
  ┌──────────┐
  │          │
  │   PSY    │
  │          │
  │          │
  └──────────┘

Po SquarePad (300×300):
  ┌────────────┐
  │▓▓ PSY  ▓▓│  ← padding po bokach
  │▓▓      ▓▓│
  │▓▓      ▓▓│
  └────────────┘

Po Resize(434) + CenterCrop(380):
  ┌────────────┐
  │   PSY      │  ← cały pies widoczny
  └────────────┘
```

## Implementacja

```python
class SquarePad:
    """Dodaje padding do obrazu PIL, tworząc kwadrat."""

    def __call__(self, image: Image.Image) -> Image.Image:
        w, h = image.size
        max_dim = max(w, h)
        pad_left = (max_dim - w) // 2
        pad_top = (max_dim - h) // 2
        pad_right = max_dim - w - pad_left
        pad_bottom = max_dim - h - pad_top

        return ImageOps.expand(image, (pad_left, pad_top, pad_right, pad_bottom), fill=0)
```
