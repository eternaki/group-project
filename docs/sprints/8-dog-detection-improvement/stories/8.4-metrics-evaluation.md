# Story 8.4 — Metryki i ewaluacja modelu

**Sprint:** 8 — Dog Detection Improvement
**Status:** Done
**Priorytet:** Medium

---

## Opis

Zdefiniowanie frameworku do ewaluacji modelu detekcji psów. Faktyczne pomiary metryk zostaną wykonane w Sprint 13, gdy dostępny będzie zbiór testowy.

---

## Metryki do pomiaru

| Metryka | Opis | Narzędzie |
|---------|------|-----------|
| mAP@50 | Mean Average Precision przy IoU≥0.50 | ultralytics `model.val()` |
| mAP@50-95 | Uśrednione mAP dla IoU 0.50–0.95 | ultralytics `model.val()` |
| Precision | TP / (TP + FP) | ultralytics |
| Recall | TP / (TP + FN) | ultralytics |
| Inference time | ms/klatka | `time.perf_counter()` |

---

## Framework ewaluacji

Aby zmierzyć metryki, potrzebny jest dataset testowy w formacie YOLO:
```
data/test/
    images/   # klatki .jpg
    labels/   # pliki .txt (YOLO format: class cx cy w h)
```

**Kiedy wykonać:** Sprint 13 (Zbieranie danych) — po zebraniu 2500 filmów i manualnej weryfikacji próbki.
